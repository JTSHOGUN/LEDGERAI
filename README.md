## ⚡ Quick Start

### 1. Install & Run Locally
```bash
chmod +x install.sh run.sh
./run.sh
```

### 2. Direct Binary Execution
```bash
chmod +x ./ledgerai-business
./ledgerai-business --port 5173
```

### 3. Docker Deployment
```bash
docker compose up -d
```

## 🛡️ Real-Market Connection Guide
1. Launch the server and navigate to `http://localhost:5173/`.
2. Connect your business in **Settings > Profile & URA EFRIS** with your actual TIN and legal name.
3. Configure your **MTN MoMo Open API Gateway** and **Airtel MoneyPay** credentials.
4. Import bank statement CSVs or link direct Open Banking feeds.
5. Post real double-entry general ledger entries with instant debit/credit balance checks.
